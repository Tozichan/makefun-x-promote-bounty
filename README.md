A working entry for the make.fun bounty "Promote make.fun's make-your-own-bounty post on X": one post of our own on X quotes make.fun's make-your-own-bounty post, with a photo of its own attached, and this repository hands in the post's address. The post itself is the entry, and places go by its replies plus reposts plus quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
